## 0. 準備

- [ ] NVDA をインストール（https://www.nvda.jp/ 日本語版）
- [ ] NVDA を起動し、**音声が出ることを確認**
- [ ] ブラウザは Chrome または Edge（NVDA との相性が最も良い）
- [ ] マウスを物理的に脇へどける（手が伸びない位置に置く。これが一番効く）

### NVDA の最低限の操作

| キー | 動作 |
|---|---|
| `Insert` + `Q` | NVDA を終了 |
| `Ctrl` | 読み上げを止める |
| `Insert` + `↓` | そこから全部読む |
| `Insert` + `Space` | ブラウズモード / フォーカスモードの切替 |
| `Tab` | 次のフォーカス可能要素へ |
| `H` | 次の見出しへ（ブラウズモード時） |
| `D` | 次のランドマークへ（ブラウズモード時） |
| `T` | 次の表へ（ブラウズモード時） |
| `Ctrl` + `Alt` + `矢印` | 表のセル間を移動 |

**「ブラウズモード」と「フォーカスモード」**: NVDA は表やリンクを読むときは
ブラウズモード、テキスト入力欄に入るとフォーカスモードへ自動で切り替わる。
入力欄から出られなくなったら `Insert` + `Space` か `Esc`。

## A. jpml_pros.html（最重要・15列1,099行）

**なぜ最重要か**: 今回直した #181（名前セルの th 化）・#182（main/スキップ

### A-1. キーボードのみで到達できるか（NVDA オフでも可）

- [ ] ページを開いて `Tab` を1回押す → **「本文へスキップ」が見える**
- [ ] そのまま `Enter` → 本文（h1〜検索欄〜表）へ飛ぶ
- [ ] 続けて `Tab` → 検索欄の開閉ボタン、検索入力欄へ順に移動できる
- [ ] `Tab` を押し続けて表内のリンクへ到達 → **フォーカスリングが常に見える**
      （固定ナビや固定ヘッダーの下に隠れない ← #179）
- [ ] 検索欄を**開いた状態**でも同じことを確認（ナビが厚くなる）
- [ ] 列見出しの「名前」などにフォーカスが当たり、`Enter` でソートできる
- [ ] ページ送りの「次へ」を連打して最終ページへ → **フォーカスが消えず、
      そのボタンに残っている**（`Tab` を押すと続きから動く ← #184）
- [ ] 「前へ」で1ページ目に戻った場合も同じ

### A-2. NVDA で読み上げを確認

- [ ] `D` を押す → 「メイン」「ナビゲーション」などランドマークが読まれる（#182）
- [ ] ナビのドロップダウンを `Tab` で順に辿る → **「連盟JPML」「鳳凰戦」
      「女流桜花」…と別々の名前が読まれる**（全部「連盟JPML」と読まれたら
      #178 の再発）
- [ ] ハンバーガーボタンが**「メニュー」**と読まれる（"Toggle navigation" ではない）
- [ ] `T` で表へ移動 → `Ctrl`+`Alt`+`→` でセルを横に移動
- [ ] **セルを移動するたびに選手名が前置されるか**（#181 の効果）
      例: 「合澤雄貴　X　リンク」のように、誰の行か分かる
- [ ] 画像リンク（X・龍龍など）で**「（新しいタブで開く）」が読まれる**（#183）
- [ ] 検索入力欄にフォーカス → **入力欄の名前が読まれる**（無言なら label 欠落）

### A-3. 体感

- [ ] スクロールが引っかからないか（1,099行 + `content-visibility`）
- [ ] 検索の反応が遅くないか
- [ ] ソートに時間がかかりすぎないか

**A-3 で引っかかりを感じた場合**: CDP がタイムアウトした件（#186 のコメント）と
関係がある可能性がある。どのページのどの操作で遅いか具体的にメモしておく。

## 記録の残し方

**見つけたことは、良し悪しを判断せずそのままメモする。**
「変な読まれ方をした」「どこにいるか分からなくなった」で十分。
原因の切り分けはあとでできる。

メモの形式（例）:

```
[A-2] jpml_pros / NVDA
表の3列目でセル移動したら、選手名ではなく「列 3」と読まれた。
→ 期待は「合澤雄貴」
```

ページ名・チェック項目番号・何が起きたか・何を期待していたか、の4つが
あれば十分に追える。
