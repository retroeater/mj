# docs/gsc

Google Search Console のエクスポート置き場。関連: #142

## 命名ルール

```
docs/gsc/<取得日>/<開始日><終了日>/<GSCのファイル名>
```

- `<取得日>` は `YYYY-MM-DD`。エクスポートを実行した日
- `<開始日><終了日>` は `YYYYMMDD` をハイフンで連結（例: `20260906-20260908`）
- 期間は**実際にデータが存在する範囲**を書く。GSC の期間指定がそれより
  広くても、実データの範囲に合わせる
- 中のファイル名は GSC のエクスポートそのまま。再取得したファイルを
  そのまま置いて差分が取れるようにするため
- 各 `<取得日>` フォルダに `README.md` を置き、その回の取得条件と
  データの確定状態を記録する

## 取得日を階層に持つ理由

GSC のデータは後から埋まる。同じ期間でも取得日が違えば数値が変わるため、
期間だけをキーにすると同一期間の再取得を残せない。

実例として、handover にある「表示48回・クリック2回」は 2026-09-09 時点の
記録だが、2026-09-12 に取り直すと 2026-09-06 の1日だけで48表示ある。
直近数日を含むエクスポートは必ず未確定として扱うこと。
